How PostHog instruments this portal

The portal is the product; PostHog measures how roaming teams use it. Orange tags above show the event each component sends.
  • Group analytics: every operator customer is a PostHog group, e.g. posthog.group('company', 'meridian-mobile'), so usage, retention and health roll up per account.
  • Person properties: role (analyst / manager / finance), team, preferred_theme.
  • Feature flag: experience-metrics-beta rolled out to one operator first; the Alerts page sits behind alerts-beta.
  • Funnel: $pageview → filter_applied → partner_scorecard_opened → report_exported.
  • Session replay: where do analysts get stuck on the map?
  • Case study: "Carrier B's weekly active users dropped 60%." Real churn risk or broken tracking?
